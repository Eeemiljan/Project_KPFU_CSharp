# Лекция 2: домашняя работа

Решение `Lecture2Exercises.sln` содержит три консольных проекта для .NET 10.

| Проект | Содержимое |
| --- | --- |
| `DataTypes` | Проект 1, оставлен в исходном состоянии: `Hello, World!`. Работа с пары в репозитории отсутствовала. |
| `TumakovChapter3` | Проект 2: упражнение 3.1 пользователя, упражнение 3.2 и домашнее задание 3.1. |
| `HomeworkTasks` | Проект 3: задачи 1–6 из `DZ_2.pdf`, выполняются последовательно. |

## Сборка и запуск

Из папки решения:

```sh
dotnet build Lecture2Exercises.sln
dotnet run --project DataTypes
dotnet run --project TumakovChapter3
dotnet run --project HomeworkTasks
```

Во втором проекте данные заданы в коде. В третьем ввод нужен для задач 2–5; программа пишет, что вводить. Если возраст некорректен, программа завершится с пояснением. При неверных данных задачи 5 программа переходит к задаче 6.

## Что разбирается в задачах

- Упражнение 3.1: `enum` описывает допустимые именованные значения; исходная переменная `accountType` и вывод `Current` сохранены.
- Упражнение 3.2: `struct BankAccount` объединяет номер, тип и баланс счёта. Номер хранится в `string` ради начальных нулей, баланс — в `decimal` (суффикс `m` у числа).
- Домашнее 3.1: `struct Employee` объединяет имя и значение перечисления `University` с вариантами КГУ, КАИ, КХТИ.
- Задача 1: `MinValue` и `MaxValue` содержат границы числовых типов. Для `char` выведены коды UTF-16; у `bool`, `string` и `object` числовых границ нет. `nint` и `nuint` — дополнительные целочисленные типы, их размер зависит от разрядности процесса.
- Задача 2: `Console.ReadLine()` читает текст, `int.TryParse` пытается получить из текста возраст. PIN остаётся строкой: `0042` не превращается в `42`. Вывод PIN сделан согласно учебному условию. `?? ""` заменяет отсутствие входной строки пустой строкой.
- Задача 3: цикл `for` перебирает символы; `char.IsLower` и `char.IsUpper` проверяют регистр, `ToUpper` и `ToLower` меняют его. Цифры и знаки сохраняются. Решение рассчитано на обычные русские и латинские буквы.
- Задача 4: цикл проверяет подстроку с каждой позиции. Считаются перекрытия: `aa` в `aaaa` встречается 3 раза. Регистр учитывается. Пустая подстрока отклоняется с пояснением. В PDF правило перекрытий не уточнено, поэтому здесь оно выбрано явно.
- Задача 5: экономия на бутылке = `normPrice * salePrice / 100`. В условии `salePrice` — процент скидки. Деление выполняется в `decimal`. Приведение положительного результата к `long` отбрасывает дробную часть, то есть округляет вниз, как требует PDF. При дробном результате это ещё не покрывает весь отпуск; для полного покрытия понадобилась бы ещё одна бутылка, но это противоречило бы требованию округлить вниз.
- Задача 6: структуры `Student` и `Drink`, перечисление категорий и массив из пяти студентов. `DateTime` хранит дату рождения. Первый цикл суммирует жидкость и чистый спирт, второй выводит доли каждого студента. Проверки знаменателей защищают от деления на ноль.

В задаче 6 объёмы измеряются в литрах. Чистый спирт = объём напитка × крепость / 100. Доля студента = его объём / общий объём × 100; для жидкости и спирта знаменатели разные. На заданных данных получается 5 л жидкости, 0,2325 л спирта, общая крепость 4,65%. Категории — условные данные из задания, а не вывод из объёма напитка.

## Ветки Git

Всего четыре локальные ветки:

- `main` — итоговое решение из трёх проектов.
- `project-1-data-types` — исходное состояние репозитория и первого проекта.
- `project-2-tumakov` — состояние после завершения второго проекта.
- `project-3-homework` — состояние с третьим проектом и задачами 1–6.

Ветка хранит состояние всего репозитория, а не отдельную папку. Изменения проектов последовательно включены в `main`. Исходный коммит пользователя сохранён в истории. Отправка новых коммитов и веток на GitHub не выполнялась.
